# Eight Sleep · Rest Pod — prototype

Clickable React prototype of the Rest Pod flow (20 screens, from the Figma section “Rest Pod · Screens”).

Live: https://maxlomaev.github.io/eightpod/

```bash
npm install
npm run dev      # http://localhost:5541
npm run deploy   # build and publish to the gh-pages branch
```

← / → step through screens, R restarts. PP Neue Montreal is not committed (commercial font); without it the UI falls back to Inter.
